1. What is the difference between class and object in Java ?
Class is a blueprint or a template that defines the properties That means attributes and behaviours or methods of objects.
Class is a logical entity that holds the structure and logic of objects .
No object, An object is an instance of a class . It represents a real world entity and holds actual data  
Open a class is instantiated using new keyword it creates an object with values assigned to its attributes .
